Как собрать у себя (Node.js 20+)

npm install npm run dev → http://localhost:3000 npm run build:static → готовый сайт в out/ Для обеих сборок: npm run build — серверная версия (VPS/Vercel).

Проверка целостности (если архив «не открывается»)

Сверьте контрольную сумму скачанного файла с SHA-256 выше — если суммы совпали, файл доехал целым и дело только в распаковщике.

Windows (PowerShell / cmd):

certutil -hashfile daro-site-static.zip SHA256

macOS / Linux:

shasum -a 256 daro-site-static.zip
