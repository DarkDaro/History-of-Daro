## Блок A — Аудио (запрошено хозяином)

Зачем единый порядок: A1 — фундамент (без него ползунок невозможен),
A2 — видимая победа, A3 — «дождь как дождь», A5 — быстрые звуковые
детали, A4 — самая крупная работа (темы страниц).

### A1. Единое аудио-ядро (фундамент)

**Проблема.** Сейчас два независимых AudioContext (`sfx.ts` и
`ambient-audio.tsx`), каждый подключён к выходу напрямую. Общая
громкость технически невозможна.

**Решение.** Новый файл `src/lib/audio-engine.ts` — синглтон:

- один AudioContext на весь сайт, создаётся лениво при первом жесте;
- шина-микшер: `master → destination`, ниже четыре подшины:
  `ambience` (дождь, дрон, гром) · `music` (темы страниц, A4) ·
  `ui` (звуки интерфейса) · `master` управляет всеми сразу;
- громкости — `GainNode`, изменения плавные (`setTargetAtTime`),
  без щелчков;
- предпочтения в localStorage: `daro-ether` (остаётся как есть),
  новые `daro-vol-master`, `daro-vol-ambience`, `daro-vol-music`,
  `daro-vol-ui`;
- обратная совместимость: `sfx(kind)` не меняет сигнатуру — вызывающий
  код (форма, тосты, палитра) править не нужно; эмбиент переезжает
  на шины без изменения звучания.

**Оценка:** 1 коммит. Риск: низкий (проверяется на слух + tsc).

### A2. Ползунок громкости

**UI.** Кнопка «Эфир» в шапке получает значок-стрелку и открывает
микшер-попап (в том же неон-стиле, что палитра Ctrl+K):

- **Общая громкость** — большой ползунок 0–100 % (мастер);
- три малых ползунка-баланса: «Дождь и город» (ambience),
  «Темы» (music), «Интерфейс» (ui) — с дефолтами 100/80/100 %;
- значения запоминаются, применяются к живому звуку мгновенно и плавно;
- `<input type="range">` со стилизованным треком/thumb (вертикальные
  риски как у студийного фейдера), aria-label, управление стрелками,
  подпись процента моно-шрифтом;
- закрытие по клику вне / Esc; на мобильном — по тапу.

**Оценка:** 1–2 коммита (попап+логика, затем полировка стилей).

### A3. Реалистичный дождь (вместо белого шума)

**Проблема.** Дождь сейчас — белый шум через lowpass 1500 Гц:
слышится «шипение вентилятора».

**Решение (послойный синтез, без файлов):**

- **База** — розовый шум (генерация буфера фильтром Пола Келлета),
  lowpass ~1000 Гц, едва заметная медленная модуляция уровня —
  «вода за куполом»;
- **Капли** — случайные короткие (20–50 мс) всплески через bandpass
  1.2–4 кГц с быстрым экспоненциальным спадом, плотность 6–14 в секунду
  с рандомизацией — «капли по металлу и брезенту»;
- **Желоба** — редкие (1–2 раза в 10–20 с) одиночные капли с высоким Q
  и нисходящим пингом — «водосток»;
- **Гром** — уже есть, остаётся без изменений;
- дрон, пэд, суб-пульс — не трогаем.

**Оценка:** 1 коммит. Слушать на A-тесте «было/стало».

### A4. Музыкальные темы по страницам

**Решение.** Подшина `music` + генератор тем (Web Audio, без файлов).
Общая тональная база — ля-минор (нынешний пэд), чтобы темы отличались,
но жили в одном мире. Тема определяется по `usePathname()`, смена —
кроссфейд 1.5–2 с.

| Раздел | Характер темы |
|---|---|
| Главная (текущая) | Главная тема: нынешний пэд-аккорд как основа, редкая верхняя фигура |
| `/books` (+ тома) | Тёплая, медленная; ре-минор, мягкие треугольные пэды |
| `/world` | Индустриальная: сильнее дрон, полутоновые кластеры, гул меди (семь корпораций) |
| `/characters` | Неонуар: блюзовая терция, медленный «контрабасовый» пульс, приглушённые духовые-подобные формантные тоны |
| `/excerpts` (+[slug]) | Чтение: самый тихий режим, глитч-эмбиент, редкие капли-эхо |
| `/timeline` | Пульс: секвенсор из тикающих нот, ощущение хронометра |
| `/armory`, `/implants` | Металл: открытые квинты, короткие pluck-блики |
| `/chronicles` | Архив: шум плёнки, детюненные тоны, редкость событий |
| `/story`, `/author` | Нейтрально-тёплые, без контрапункта |

Технически: одна структура «дрон + пэд-аккорды + редкая мелодическая
фигура из лада раздела», темы = наборы параметров (лад, темп LFO,
набор частот, плотность событий) — ~1 файл `src/lib/audio-themes.ts`.
Тему можно заглушить ползунком «Темы» (A2), дождь и SFX продолжают жить.

**Оценка:** 3–5 коммитов (ядро тем + 2–3 пачки разделов + полировка).
Риск: средний — главный не музыкальный, а «не превратить в какофонию»;
лечится слушанием после каждой пачки.

### A5. Больше системных звуков

**Новые виды SFX** (к существующим hover/click/confirm/deny/boot/whoosh):

| Звук | Характер | Где зазвучит |
|---|---|---|
| `glitch` | рваный битовый шорох 60–120 мс | ховер по глитч-заголовкам, открытие засекреченного файла таймлайна |
| `type` | тихий тик терминала | печать текста в читалке фрагментов (троттлинг жёстче hover) |
| `transition` | короткий «вжух» | смена страницы (уже есть whoosh — вайрится в роутер) |
| `palette` | двойной блип вверх | открытие Ctrl+K; `deny` уже есть на ошибку |
| `open` / `close` | засов/панель | досье-панели персонажей и мира |

**Правила спама:** каждый вид со своим троттлингом; `ui`-подшина тише
прочих; всё глохнет вместе с «Эфиром». Ничего не звучит до первого
жеста.

**Оценка:** 2–3 коммита (движок звуков + вайринг по компонентам).

## Блок B — укрепление сайта (аудит: что слабо и хрупко)

### B1. Линтер контента в CI — главный хрупкий пункт

Сайт растёт: слаги, внутренние ссылки, перекрёстные «смежные файлы» —
всё держится на ручной аккуратности. Один опечатанный href = битая
ссылка на живом сайте.

**Решение:** `scripts/check-content.mjs` (node, без зависимостей):
уникальность всех слагов; каждый внутренний href из контента существует
как маршрут; каждый фрагмент/хроника имеет страницу; sitemap покрывает
все маршруты. Запуск в `deploy.yml` перед сборкой — падение ломает
деплой до публикации, а не после.

**Оценка:** 1 коммит.

### B2. OG-изображения для соцсетей

Сейчас ссылка на сайт в Telegram/VK без превью. Нужна хотя бы одна
`public/og.png` (1200×630, обложка-логотип «ДАРО//») + og-теги с
`asset()`; в идеале — по одной на раздел (обложка тома для `/books`,
досье для `/characters`…).

**Оценка:** 1–2 коммита (общая сразу, per-section — по мере желания).

### B3. content.ts — разбиение на модули (отложить)

~2000 строк, один файл — уже тяжело листать. Разбить на
`src/content/{books,world,characters,excerpts,...}.ts` с ре-экспортом
из `content.ts` (импорты нигде не меняются). **Делать только когда
правки контента станут частыми** — сейчас это перестановка мебели.

### B4. Доступность и аккуратность — попутно

`prefers-reduced-motion` для тяжёлых анимаций; фокус-кольца попапа
микшера; проверки клавиатурой по ходу A2/A4/A5. Отдельной работы не
требует.

### B5. Процессное (записать, не кодить)

- PAT живёт 7 дней — чеклист «что делать при отказе push» уже в
  DEPLOY.md; дополнить: «прислать новый токен в чат».
- Архивы `releases/*.zip` пересобираются вручную
  (`scripts/build-releases.sh`) перед пушем — оставить как есть,
  добавить строку-чеклист в DEPLOY.md.
