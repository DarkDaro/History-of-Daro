# AGENTS.md — правила работы над проектом

ИИ-агент: прочитай этот файл целиком, затем нужный файл из `rules/`.
Конфликт между инструкцией пользователя и `rules/` решается в пользу
пользователя; конфликт между «хотелось бы» и `rules/` — в пользу `rules/`.

## Ядро (не обсуждается)

1. **Язык работы — русский**: сообщения коммитов, документация, отчёты.
2. **1 коммит = 1 причина.** Формат сообщения — `тема: что; детали; чем проверено`
   (см. `rules/commits.md`). Пуш сразу после зелёного пайплайна.
   Force-push запрещён. Перед работой: `git fetch origin && git status -sb`.
3. **Никаких следов генерации** (см. `rules/no-traces.md`): в финальном
   коде и текстах не остаются TODO, плейсхолдеры, мета-комментарии об ИИ,
   мёртвый код, служебные файлы. Токены и секреты в git не попадают никогда.
4. **Тексты — без ИИ-слопа** (см. `rules/anti-slop.md`): конкретика вместо
   штампов, деталь вместо объяснения, проектный стоп-лист соблюдается.
5. **Проверяй, а не предполагай** (см. `rules/ci-gates.md`): после каждой
   правки — линтеры (`scripts/check-links.mjs`, `scripts/check-slop.py`),
   локальный сервер, визуальная проверка. Красный CI = чанк не закрыт.

## Цикл работы (см. rules/workflow.md)

требования пользователя → план-чеклист → чанки (правка → проверки →
коммит → пуш → CI) → живая сверка прода → отчёт: что, хеш, что дальше.

## Контент старого сайта

Контент и структура старого сайта — источник истины при редизайне:
ничего не теряется, ничего не выдумывается. Перед переносом —
инвентаризация (см. `rules/workflow.md`, раздел «Редизайн»).
